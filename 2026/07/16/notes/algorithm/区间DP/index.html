区间DP

最长回文子序列

解题思路

思路1：由于回文子序列的定义，所以可以求 $s$ 和 $s-reversed$ 的最长公共子序列
如,s = “eacbba”，最长回文子序列为 “abba”
s_reversed = “abbcae”, 它和 s 的最长公共子序列为 “abba”

思路2：选或不选，从两侧向内缩小问题规模

定义 dfs(i,j) 表示从 s[i] 到 s[j] 的最长回文子序列长度。
$$
dfs(i, j) = \begin{cases} dfs(i + 1, j - 1) + 2, \quad s[i] = s[j] \
max(dfs(i + 1, j), dfs(i, j - 1)), \quad s[i] \neq s[j]
\end{cases}
$$

递归边界
$$
dfs(i, i) = 1 \
dfs(i+1, i) = 0
$$

递归入口
$$
dfs(0, n-1)
$$

记忆化搜索

  • 时间复杂度：$O(n^2)$
  • 空间复杂度：$O(n^2)$

翻译成递推
$$
f[i][j]=\begin{cases} 0 \quad i > j \
1 \quad i = j \
f[i + 1][j - 1] + 2 \quad s[i] = s[j] \
max(f[i + 1][j], f[i][j - 1]) \quad s[i] \neq s[j]
\end{cases}
$$

循环顺序
关于 $i$, 由于 $i$ 依赖于 $i+1$, 所以 $i$ 要倒序枚举；
关于 $j$, 由于 $j$ 依赖于 $j-1$, 所以 $j$ 要正序枚举；

迭代做法

  • 时间复杂度：$O(n^2)$
  • 空间复杂度：$O(n^2)$
